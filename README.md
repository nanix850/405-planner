405 Planner
Une application web responsive pour organiser les devoirs, les révisions et l'emploi du temps.
Fonctionnalités
Tableau de bord
Devoirs avec échéance et statut terminé
Séances de révision
Emploi du temps de secours
Mode sombre
Export/import JSON
Sauvegarde locale, sans compte
Utilisation locale
Ouvrir `index.html` dans un navigateur.
GitHub Pages
Créer un dépôt GitHub.
Ajouter `index.html`, `style.css` et `script.js`.
Aller dans Settings > Pages.
Choisir la branche `main` et le dossier `/ (root)`.
Enregistrer puis attendre la publication.
Les données restent dans le navigateur de chaque utilisateur.
